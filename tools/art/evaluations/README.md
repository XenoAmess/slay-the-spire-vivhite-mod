# art/evaluations

本目录保存针对已批准或明确豁免素材的离线验收脚本。它们与
[`candidates/`](../candidates/README.md) 的研究候选不同：验收脚本验证真实消费者的
尺寸、Alpha、布局和 SourceOver 观感，但输出仍只属于 `.work/` 证据，不会自动更新
`Vivhite/Vivhite/skins/ironclad/`。

- [`multiplayer_gestures/README.md`](multiplayer_gestures/README.md)：四张多人手势图的
  用户授权例外与 Vulkan/Alpha 验收。

所有脚本都应从仓库根目录运行，并遵守 `AGENTS.md` 的透明素材与不触碰游戏进程规则。
