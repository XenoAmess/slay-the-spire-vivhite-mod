# 2026-08-22 sts2-ascend 复盘模型双轨制（ox-alpha 优先每局 / k3 兜底每10局）

## 需求

每局对局结束后探测 **Ox Alpha Free**（`openrouter/stealth/ox-alpha`）是否可用：
可用则每局用它做 opencode 复盘；不可用则维持 k3（`kimi-for-coding/k3`）每 10 局一次。

## 实现要点（brain/llm_review.py）

1. **模型 ID 确认**：opencode CLI 里该模型的唯一 id 是 `openrouter/stealth/ox-alpha`
   （`opencode models` 可列出；没有 `opencode/ox-alpha` 这样的条目）。
2. **探测方式**：`opencode models` 子进程，60s 超时；逐行 strip 后做集合匹配。
   每局一次、开销 2~5 秒，相对一局 10+ 分钟可忽略，无需缓存。
3. **节奏解析**：`resolve_review_plan(cfg, binary)` → `(model, every, source)`。
   优先模型可用 → `every=preferred_every_runs(默认1)`；不可用/探测失败 → 回退 `(k3, 10)`。
4. **失败冷却**：优先模型复盘执行失败（非零退出/超时/异常）写入
   `knowledge/preferred_model_state.json` 的 `unavailable_until`（默认 6 小时）。
   关键保护——否则模型挂限速时每局都会白等一个 25 分钟超时。
   注意：**只有传输层失败才记冷却**；"复盘成功但没产生文件变更"不算失败，不清零节奏。
5. **prompt 文案联动**：`build_prompt` 增加 `every` 参数，"每 N 局复盘"的措辞跟随实际节奏。

## 验证

- `resolve_review_plan` 实测三态：可用 → `('openrouter/stealth/ox-alpha', 1, 'preferred')`；
  冷却中 → `('kimi-for-coding/k3', 10, 'fallback')`；冷却解除 → 恢复 preferred。
- `py -3 brain/selfcheck.py` → SELFCHECK OK。
- 测试产生的 `preferred_model_state.json` 已清理，避免把人为冷却带进正式运行。

## 注意

- 大脑下次启动（或被复盘自重启）即生效，无需改 agent.py/runner.py。
- 若 ox-alpha 从 OpenRouter 下架，改 `config.json` 的 `llm.preferred_model` 即可换模型，无需改代码。
