## 总装边界

最终 JSON 以 `hybrid_cast_set` 为结构基线，只允许四类语义差量：

1. `skeleton.hash` 改为 `vivhite-hybrid-v3-final-v1`；
2. 三个 neutral loop 的完整 `.slots` 取自 `hybrid_neutral_v3`；
3. `animations.hurt.bones` 取自 `hybrid_hurt_neutral`；
4. `animations.die.bones` 中仅 `vivhite_rig` 与 `vivhite_death_pose` 取自
   `hybrid_death_v3`。

没有整段覆盖 hurt 或 die。这样既保留专项骨动画，也保住 cast-set 中 action slot、三个刚性
动作 attachment、EyeFire 骨架、events、slot reset 与 transition mix。把最终 JSON 反向恢复
以上四类字段后，与 cast-set 基线语义完全相等；独立审计记录了 432 个允许叶差、0 个越界叶差。

## 踩坑与约束

- 分项候选不是线性“最后一个覆盖前一个”：neutral、hurt、death 都是不同分支，只能按字段合并。
- `hybrid_death_v3` 少 action bone/slot 上下文；整段复制 die 会丢 action 清理。
- hurt 真正新增的是 `.bones`；整段复制会把 neutral loop reset 回退。
- `.import` 与 `.uid` 是 Godot cache，不属于 8 authored 文件，也不进入 30 文件 runtime。
- `CopyModOnBuild=false` 不会禁 PCK 导出；任何完整 PCK 门禁都必须使用 `.work` 隔离项目并显式
  重定向 `ModPckPath`、`ModOutputDir` 与 `RitsuLibDeployDir`。
- `clear_vfx` 的真实 C# 实现只隐藏外部 EyeFire，不会清 Spine slash/sigil，也不会 Kill slash
  Tween。是否需要新增目标动画 t=0 reset，必须先由连续状态机复现，不能凭静态推导扩张改动。
