# Vivhite 0.2.1 版本同步记录

日期：2026-09-01

## 变更理由

0.2.1 是针对创意工坊评论反馈的兼容性修复版本。它包含两项可复现的玩法语义修复：

- 修正钨合金棍（或其他原生减伤/阻挡效果）存在时的生命支付判定；只有付款者没有实际伤害结果或已经死亡才会阻止后续效果。
- 将事件循环生成的临时复制牌明确设为本回合 0 费并消耗，避免复制牌正常进入牌库、跨战斗保留。

同时，发布说明补充了当前仅在 Steam `public-beta` / STS2 `0.111.0` 上完成的验证范围，并把 Vulkan 说明限定为本机已验收的默认路径，而不是对其他渲染后端的兼容承诺。

## 版本对齐

- 源 manifest `Vivhite/Vivhite.json`：`0.2.1`
- `Vivhite/README.md` 与 `Vivhite/README.en.md`：当前版本快照和 manifest 示例均更新为 `0.2.1`
- RitsuLib 依赖仍为 `0.5.14`，最低游戏版本仍为 `0.111.0`

历史 0.2.0 文档和验收记录保持不变；本记录只描述新发布候选的版本边界与原因。上传创意工坊前，须让 `workshop/description.bbcode`、预览图及上传 change note 与 0.2.1 同步，并在稳定训练证据成立后再发布。
