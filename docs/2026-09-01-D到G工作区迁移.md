# D 到 G 工作区迁移

## 目标

将项目从：

`D:\workspace\slay-the-spire-vivhite-mod`

迁移到：

`G:\workspace\slay-the-spire-vivhite-mod`

迁移必须保留主仓暂存区、未暂存改动、未跟踪与 ignored 文件、Brain 学习数据、复盘取证现场、AI 美术原始资产、TTS 模型，以及 `STS2-Agent`、`MOSS-TTS-Nano`、`index-tts` 三个嵌套仓库。

## 已确认的兼容性结论

- Vivhite 构建、部署和 sts2-ascend 生产代码均从脚本或项目文件位置推导根目录，不需要因换盘修改生产代码。
- `Vivhite/local.props` 已指向 G 盘游戏和 C 盘 Godot，不需要改址。
- Python 虚拟环境、Godot 导入缓存、MSBuild `bin/obj` 与临时构建产物不能视为可移植缓存；迁移后需要冒烟验证或重建。
- `.runtime` 和在线锁是会话状态。历史文件可保留，但迁移后必须由 G 盘 `Start-Agent.ps1` 创建新会话。
- 历史日志、美术验收报告、复盘 salvage 中的 D 盘路径属于取证内容，不做全仓替换。
- `sts2-ascend/tmp_review_dump.py` 原有 D 盘输出硬编码已改为根据脚本位置生成输出。
