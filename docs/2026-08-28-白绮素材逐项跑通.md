# 白绮素材逐项跑通

## 顺序原则

从静态、小尺寸、无场景依赖的素材开始，每次只完成和验收一项，再进入下一项。
当前顺序为：

1. 顶栏头像 `icon.png`；
2. 顶栏头像轮廓 `icon_outline.png`；
3. 地图标记；
4. 选人按钮；
5. 多人手势；
6. 选人动画；
7. 篝火动画；
8. 战斗与商店动画。

战斗放在最后，因为它同时涉及三分之四侧身视角、人体骨链、多顶点网格、权重、
八个动画和四个 VFX 事件，不能用正面立绘或四顶点平面代替。

`gpt-image-2`、`background=transparent`、`1:1`、`1K`、`quality=high`，参考已验真的
EvoLink 身份母图和用户头像参考。

该次结果在第一次就满足用途要求，因此没有继续消费第 2 次尝试。验收结论：

- 银发、紫瞳、金色圆框眼镜、蓝蝶、高领和紫水晶均清楚；
- 单人正面头肩构图，方形安全区内没有裁切；
- 没有武器、文字、标志、额外人物或棋盘格；
- 原图是真 RGBA；缩放后的四角 Alpha 均为 0；
- 在实际 `85 × 85` 尺寸仍能辨认身份特征。

只做等比缩放，不执行抠图、色键、阈值化、Alpha 收缩或边缘修补。当前批准成品为：

这一步只证明“生成 → 原图归档 → 尺寸适配 → 实际尺寸预览”的静态资源链路。
完整皮肤仍保持 fail-closed，不为测试一张头像而部署半套替换包。

## 第二项：顶栏头像轮廓

原版 `icon_outline.png` 的像素契约不是另一张彩色头像，而是与 `icon.png` 对齐、面积
略大的纯白实心剪影。它由游戏垫在头像后方形成高亮白边。

EvoLink 第一次生成保存在：

`assets/vivhite-ironclad/generated/evolink-paid/2026-08-28/0007-ui-icon-outline-attempt-01/`

该结果是真透明、纯白实心人物剪影，发型、蝴蝶、侧饰和肩部构图正确，但直接缩到
`85 × 85` 后与头像面积接近，叠图时白边偏窄。第二次只强化“整体外扩”要求，结果保存在
`0008-ui-icon-outline-attempt-02/`；模型把人物中心挖空成光环，违反实心遮罩契约，因此
作为失败样本保留且不参与后续血缘。

第一次输出已经是合格的 EvoLink 原生 Alpha 遮罩，所以不继续付费生成。只对该原图做
规则允许的等比尺寸适配，保留 100%、104% 和 106% 三组 `85 × 85` 候选与叠图预览：

`assets/vivhite-ironclad/generated/ui-sizing-tests/`

最终选择 106% 候选：白边在头发、侧饰、蝴蝶和肩部外侧更连续，同时没有形成过粗的
白色包边。批准成品为：

`assets/vivhite-ironclad/approved/ui/icon_outline.png`

对应的实际尺寸叠图预览是：

`assets/vivhite-ironclad/generated/ui-sizing-tests/icon-outline-attempt-01-overlay-scale-106.png`

本步骤没有用代码生成、膨胀、阈值化或修补 Alpha；代码只裁取相同中心并等比缩放已验真
的模型原生透明图。该语义素材在两次付费尝试后停止。
