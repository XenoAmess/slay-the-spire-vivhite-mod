# 白绮素材逐项跑通

## 顺序原则

从静态、小尺寸、无场景依赖的素材开始，每次只完成和验收一项，再进入下一项。
当前顺序为：

1. 顶栏头像 `icon.png`；
2. 顶栏头像轮廓 `icon_outline.png`；
3. 地图标记；
4. 选人按钮；
5. 多人手势；
6. 选人动画；
7. 篝火动画；
8. 战斗与商店动画。

战斗放在最后，因为它同时涉及三分之四侧身视角、人体骨链、多顶点网格、权重、
八个动画和四个 VFX 事件，不能用正面立绘或四顶点平面代替。

## 第一项：顶栏头像

第一次 EvoLink 原生透明生成保存在：

`assets/vivhite-ironclad/generated/evolink-paid/2026-08-28/0006-ui-icon-attempt-01/`

目录内保留未经处理的 `output.png`、逐字 Prompt 和非敏感实际请求参数。请求使用
`gpt-image-2`、`background=transparent`、`1:1`、`1K`、`quality=high`，参考已验真的
EvoLink 身份母图和用户头像参考。

该次结果在第一次就满足用途要求，因此没有继续消费第 2 次尝试。验收结论：

- 银发、紫瞳、金色圆框眼镜、蓝蝶、高领和紫水晶均清楚；
- 单人正面头肩构图，方形安全区内没有裁切；
- 没有武器、文字、标志、额外人物或棋盘格；
- 原图是真 RGBA；缩放后的四角 Alpha 均为 0；
- 在实际 `85 × 85` 尺寸仍能辨认身份特征。

只做等比缩放，不执行抠图、色键、阈值化、Alpha 收缩或边缘修补。当前批准成品为：

`assets/vivhite-ironclad/approved/ui/icon.png`

这一步只证明“生成 → 原图归档 → 尺寸适配 → 实际尺寸预览”的静态资源链路。
完整皮肤仍保持 fail-closed，不为测试一张头像而部署半套替换包。
