# 白绮素材逐项跑通

## 顺序原则

从静态、小尺寸、无场景依赖的素材开始，每次只完成和验收一项，再进入下一项。
当前顺序为：

1. 顶栏头像 `icon.png`；
2. 顶栏头像轮廓 `icon_outline.png`；
3. 地图标记；
4. 选人按钮；
5. 多人手势；
6. 选人动画；
7. 篝火动画；
8. 战斗与商店动画。

战斗放在最后，因为它同时涉及三分之四侧身视角、人体骨链、多顶点网格、权重、
八个动画和四个 VFX 事件，不能用正面立绘或四顶点平面代替。

略大的纯白实心剪影。它由游戏垫在头像后方形成高亮白边。

EvoLink 第一次生成保存在：

`assets/vivhite-ironclad/generated/evolink-paid/2026-08-28/0007-ui-icon-outline-attempt-01/`
