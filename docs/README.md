# 工程文档索引

`docs/` 是本仓库的追加式工程记录库：它保存设计决策、真机证据、故障复盘、验收结果和发布回执，而不是另一份会自动覆盖现行规则的配置文件。截至 2026-09-02，目录包含按日期命名的报告、三份长期维护的美术规范，以及 `evidence/`、`screenshots/` 两个证据目录。

## 先读什么

新成员或新的维护代理建议按以下顺序阅读：

1. 根目录 [`AGENTS.md`](../AGENTS.md)：最高优先级的当前操作、安全、素材和生命周期契约。
2. 根目录 [`README.md`](../README.md)：项目地图和可复制的快速开始（由根项目维护）。
3. 子项目入口：[`Vivhite/README.md`](../Vivhite/README.md)、[`sts2-ascend/README.md`](../sts2-ascend/README.md)、[`tools/art/README.md`](../tools/art/README.md)、[`tools/test/README.md`](../tools/test/README.md)。
4. 发布与素材入口：[`workshop/README.md`](../workshop/README.md)、[`assets/vivhite-ironclad/README.md`](../assets/vivhite-ironclad/README.md)、[`prompts/README.md`](../prompts/README.md)。

## 事实源优先级

- 当前规则、禁止事项、路径边界和无人值守行为：以 `AGENTS.md` 及对应子项目 README 为准。
- 日期报告：记录当时的证据和变更原因；它们可能描述已经被修正的旧方案。引用历史结论时必须同时检查报告顶部的“现行规则指针”和当前代码。
- `evidence/` 与 `screenshots/`：只读证据素材，不是运行时输入。截图是单幅成品；atlas/spritesheet 的布局判断仍须查阅相邻 atlas/Spine 元数据和消费者源码。
- `sts2-ascend/knowledge/`、`.runtime/`、各子项目 `.work/`：由运行器或验收工具维护，不能手工改写来制造“通过”。
- 报告文件采用 UTF-8；新增报告沿用 `YYYY-MM-DD-主题.md`，完成一项任务后记录问题、证据、修复、验证和遗留风险。
