# sts2-ascend 原生终局分数与解锁落盘

## 问题与根因

人工游玩死亡后，游戏会先进入终局引导，再播放总结、累计角色分数并依次展示解锁内容。旧自动游玩链在
`GAME_OVER` 直接调用 `NGameOverScreen.ReturnToMainMenu`。这个调用能离开终局界面，但没有点击原生
`NGameOverContinueButton`，因而绕过了游戏自己的总结协程。表现并非单纯“经验条没有显示”：角色分数、
按分数授予的 epoch/解锁以及对应存档都可能没有执行。

修复原则是让自动游玩只操作真实原生按钮，并以原生 UI 的可操作状态作为持久化屏障，不在 Brain 中
仿造分数或直接改游戏存档。

## Agent 与 MCP 协议

STS2-Agent 的状态契约提升到 `state_version=12`、`agent_view_version=7`，`game_over.phase` 有三个值：

- `intro`：真实 Continue 可见、启用且在场景树中；只暴露 `continue_game_over`。
- `summary_animating`：Continue 已消失而 MainMenuButton 尚未就绪；不暴露离开动作。
- `summary_ready`：真实 MainMenuButton 可见、启用且在场景树中；只暴露
  `return_to_main_menu`。

`continue_game_over` 对 `NGameOverContinueButton` 执行 `ForceClick()`；
`return_to_main_menu` 对 `NReturnToMainMenuButton` 执行 `ForceClick()`。后者不再调用
`NGameOverScreen.MethodName.ReturnToMainMenu`。MCP client 与完整工具目录同步暴露
`continue_game_over`，因此 Brain HTTP 路径和 MCP 人工/模型路径遵循同一结算协议。

## Brain 顺序与幂等边界

Brain 的终局顺序固定为：

1. `intro` 点击 `continue_game_over`。
2. `summary_animating` 只等待原生总结协程。
3. `summary_ready` 首次出现时，先请求 Brain 自己的角色统计、运行日志和轮换账本幂等落盘。
4. Brain 账本确认完成后的下一次轮询，才点击真实 `return_to_main_menu`。
5. 随后的每个 `UNLOCK` 屏只用 `confirm_unlock` 逐个确认；按钮未就绪时等待，不盲点屏幕。

这一屏障保证游戏原生分数/解锁存档先完成，Brain 的分角色统计随后完成，最后才允许轮换到下一局。
若 Continue 的 HTTP 回执丢失，Brain 通过 `can_continue` 消失或 phase 前进来确认动作已应用；若返回主
菜单的回执丢失，`MAIN_MENU`、`TIMELINE` 或 `UNLOCK` 都可证明动作已应用。重复终局状态仍由 run ID
与既有终局账本去重，不重复累计局数或翻转轮换。

## 验证门禁

自动化验证覆盖：

- 首个终局动作必须是 `continue_game_over`，不能退回 `continue_run`、通用 proceed 或直接返回。
- 总结动画期间不能离开；MainMenuButton 就绪前不能提交 Brain 终局账本。
- Brain 账本提交完成前不能点击返回；完成后必须点击真实按钮。
- 连续多个 UNLOCK 屏逐一确认。
- Agent 的 Continue/Return 都解析并点击专用原生按钮，状态端同时检查 Visible、Enabled 与
  `IsVisibleInTree()`。
- MCP server/client 都包含专用终局动作。
- 回执丢失、重连旧终局与重复轮询不制造重复统计。

真机验收必须等本轮 Mod 代码和全量美术资源一起构建部署后执行。届时至少观察一局失败结算，确认总结
分数发生变化、解锁页可连续通过、重新进入角色界面后进度仍在，并检查日志中没有直接终局跳转。

## 经验与注意事项

- “成功回到主菜单”不能证明终局落盘成功；必须追踪真正承担副作用的原生按钮与协程。
- UI 是否可见不能只读 `Visible`；节点脱离场景树或被父节点隐藏时也不可操作。
- 游戏原生存档与 Brain 学习账本是两个事务。正确顺序是原生事务完成，再提交 Brain 事务，最后离开
  界面；不能用其中一份成功推断另一份成功。
- UNLOCK 是总结之后的正常队列，不是异常弹窗。用固定坐标盲点会在动画延迟、分辨率变化或多解锁时
  再次跳过内容。
