# 2026-08-26 IndexTTS 参考音频停顿压缩

## 问题与结论

原 `sts2-ascend/tts/reference_voice_15s.wav` 是 45.371792 秒母带的逐样本前缀硬裁，旧文件为
24kHz、单声道、PCM16，长度 359999 帧（14.999958 秒）。15 秒刀口恰好位于静音中，没有切断尾字；
前 15 秒也是母带中语音密度最高的连续窗口。问题不是选错窗口或底噪，而是有限参考窗口里有多段较长停顿。

本次采用保守的停顿压缩，不做全局 VAD 硬拼，也不做降噪、EQ、动态压缩或响度拉升。最终文件保留原有
发声内容和短自然停顿，只压缩 5 个明确的内部低能量区间，长度变为 307440 帧（12.810 秒）。

## 可复现参数

工具：`sts2-ascend/scripts/prepare_reference_voice.py`，仅使用 Python 标准库。

- 输入母带：`tts/reference_voice.wav`
- 最长取样：前 15 秒
- 静音判断：PCM16 绝对 RMS `-45 dBFS`
- 窗长 / 步长：20ms / 10ms
- 处理条件：仅处理两侧都有语音且严格长于 400ms 的内部静段
- 保留停顿：200ms
- 接缝：8ms 线性互补 crossfade；crossfade 前额外保留 8ms，使成品停顿仍为 200ms
- 输出：24kHz、单声道、PCM16，原子替换

从 `sts2-ascend` 目录运行：

```powershell
py -3 scripts/prepare_reference_voice.py --dry-run
py -3 scripts/prepare_reference_voice.py
```

本次检测并压缩的母带时间区间为：

- 3.240–3.810 秒（570ms）
- 5.000–5.540 秒（540ms）
- 7.540–8.300 秒（760ms）
- 10.020–10.570 秒（550ms）
- 12.200–12.970 秒（770ms）

约 390ms 的第一处自然停顿没有处理。工具不桥接短暂非静音，也不处理首尾静音，避免吞掉气声、呼吸和弱尾音。
