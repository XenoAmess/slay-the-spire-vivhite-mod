# sts2-ascend 全栈启动记录

## 结果

按项目统一入口执行 `sts2-ascend/scripts/Start-Agent.ps1`。本地 fork 的 STS2-Agent 构建成功并部署，游戏以 Vulkan 启动，runner/session 创建完成，最终报告 `Stack ready`；brain active，API 为 `http://127.0.0.1:8080`。

## 环境注意事项

首次启动因当前 PowerShell 解析到 `C:\Program Files\dotnet\dotnet.exe` 且找不到 SDK 而失败。显式设置项目记录的 `DOTNET_ROOT=C:\Users\xenoa\AppData\Local\Microsoft\dotnet` 并将该目录置于 PATH 首位后，构建与启动均正常。

本次只启动自动游玩全套，没有触发 Bilibili 开播。
