# 2026-08-22 白绮角色 Mod Demo 搭建与真机测试

## 任务

为《杀戮尖塔 2》（v0.111.0）制作角色 Mod「白绮」：可运行 Demo + 真机自测。
基础库选择 RitsuLib，教程站：<https://tutorials.sts2modding.com/>。

## 最终成果（已验证）

- 角色「白绮」出现在角色选择界面并可开局：75 HP / 99 金币，名称/描述/遗物中文本地化全部生效。
- 初始卡组：4×白绫打击（6 伤害）+ 4×白绫防御（5 格挡），卡面文本、卡框白调色正常。

- 战斗实测：打出打击敌人 43→37，打出防御获得 5 格挡，能量 3/3→1/3 正常消耗。
- 控制台 `card VIVHITE_CARD_VIVHITE_STRIKE` 成功发卡，日志确认 7/7 内容注册成功、0 失败。
- 截图证据在 `docs/screenshots/`。

## 技术路线（关键决策）

1. **使用官方模板起步**：`dotnet new install STS2.RitsuLib.ModTemplate` → `dotnet new ritsulibmod -n Vivhite`。
   模板自带角色三池、占位场景/图片、中英文本地化、manifest、PCK 导出构建脚本，省去手工搭 Godot 工程。
   仓库：NothingFumo/RitsuLibModTemplate（即 alkaid616/RitsuLibModTemplate）。
2. **RitsuLib 版本**：主线 `STS2.RitsuLib` 0.5.14（0.5.12 起支持游戏 0.111.0）。
   游戏侧部署用 GitHub Release 的 `STS2.RitsuLib.0.5.14.github.zip`，解压到 `<游戏目录>/mods/STS2-RitsuLib/`。
   manifest 依赖写 `{ "id": "STS2-RitsuLib", "version": "0.5.14" }`（注意：旧写法 `min_version` 已不支持）。
3. **Mod 三件套**：`dll`（dotnet build）+ `pck`（Godot --headless --export-pack）+ `{modid}.json`，
   构建脚本自动复制到 `mods/Vivhite/`。

## 环境搭建步骤（本机从零复现）

1. 安装 .NET 9 SDK（用户目录）：`dotnet-install.ps1 -Channel 9.0 -InstallDir "$env:LOCALAPPDATA\Microsoft\dotnet"`。
2. 安装 .NET 8 **运行时**（Godot 编辑器自身需要）：`-Channel 8.0 -Runtime dotnet` 同上目录。
3. 设置用户环境变量：`DOTNET_ROOT=<dotnet目录>`，PATH 追加该目录。
4. 下载 Godot 4.5.1 **Mono**（godotengine 官方 stable），解压即用。
5. 游戏根目录创建 `steam_appid.txt`（内容 `2868840`），否则非 Steam 启动报 "No appID found"。
6. `Vivhite/local.props` 填写 `Sts2Dir` 与 `GodotExe`（被 gitignore，不入库）。

## 踩过的坑（重要）

1. **winget 装 SDK 会挂起超时**：改用官方 `dotnet-install.ps1` 脚本，注意系统默认执行策略会拦脚本，
   用 `powershell -ExecutionPolicy Bypass -File ...` 运行。
2. **Godot Mono 编辑器需要 .NET 8 运行时**，与编译 Mod 用的 .NET 9 SDK 是两回事；
   且 hostfxr 找不到用户目录安装的运行时，必须设 `DOTNET_ROOT`，否则 `--import` 假死无输出。
3. **PowerShell 5.1 读取无 BOM 的 UTF-8 脚本会按 GBK 解析**：中文注释会导致莫名其妙的解析错误
   （`Unexpected token '}'`）。**含中文的 .ps1/.psm1 必须保存为 UTF-8 with BOM**。
4. **`Start-Process -ArgumentList` 传数组不按引号分组**：`--export-pack "Windows Desktop"` 会被拆成两个参数，
   报 `Invalid export preset name: Windows.`。带空格的参数要拼成一个整体字符串传入。
5. **模板基于旧版游戏 API**：`DamageCmd.Attack(...).FromCard(this)` 在 0.111.0 必须带 `cardPlay` 参数；
   `MaterialUtils.CreateRgbShaderMaterial` 已废弃，改用 `CreateReplaceHueShaderMaterial`。
6. **游戏控制台逐键输入会丢"空格"**（keybd_event 和 SendInput 扫描码都丢）：改用剪贴板 `Ctrl+V` 粘贴。
7. **WinRT OCR 中文语言标记是 `zh-Hans`**，`zh-Hans-CN` 无法创建引擎；英文 `en-US` 正常。
   实际测试中"直接看图"（Read 工具读 PNG）比 OCR 更可靠，OCR 适合批量日志式验证。
8. **首次启用 mod 的流程**：启动 → 弹窗"是否加载模组" → 选是后游戏退出 → 再启动 → "无 mod 存档已复制"提示。
   mod 存档与原版存档分离（`modded/` 目录）。
9. Godot 无 BOM 的 `.tscn`/`.json` 资源文件不受影响，只有 PowerShell 脚本有 BOM 要求。

## 真机测试工具链

`tools/test/GameTest.psm1`（PowerShell 模块，UTF-8 BOM）：

- `Save-Screenshot -Path <png>`：GDI 截全屏/区域。
- `Get-OcrText -Path <png> [-Language zh-Hans]`：WinRT OCR。
- `Invoke-MouseClick -X -Y`、`Move-Mouse`：鼠标（user32）。
- `Send-Key -VkCode`、`Send-Text -Text`：键盘（SendInput 扫描码方式，Godot 兼容性最好）。
- 游戏控制台：`` ` ``（VK 0xC0）开启；`card <ID>` / `dump` / `win` / `kill` / `fight <ID>` 等。
- 游戏日志：`%APPDATA%\SlayTheSpire2\logs\godot.log`，注册/出牌/控制台指令都有日志，grep 即可验证。
- RitsuLib 自带调试日志查看器：`http://127.0.0.1:18742`（token 见日志）。
