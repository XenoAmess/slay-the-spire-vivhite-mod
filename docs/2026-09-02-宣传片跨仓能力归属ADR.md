# ADR：宣传片能力的跨仓归属与白绮首片落地

日期：2026-09-02

状态：Accepted（首片仍需语义审核和人工 signoff）

## 背景

白绮宣传片需要录屏、证据、旁白、字幕、混音和导出，同时这些能力中有一部分
也适用于 CK3 或其他媒体项目。若把游戏状态、OBS 控制和白绮语义塞进
`xar_promo_toolchain`，通用工具会被单一项目绑死；反过来若在白绮仓库复制
媒体哈希、渲染和审核核心，又会产生两套不一致的审计链。

## 决策

### `xar_promo_toolchain`（通用能力）

- 通用 capture receipt：媒体字节/大小/SHA-256、时间基准、有序 marks、clean spans
  和证据引用；不解释 span 是否是“有效白绮镜头”。
- 可配置 evidence roles、claim binding、review checklist，以及人工 signoff/export
  的结构性门禁。
- 多轨音频计划和确定性 FFmpeg filtergraph；支持 narration/game/SFX/BGM 的通用
  trim、delay、gain、fade、duck。BGM 的选曲、授权和审美仍属于项目。
- FFmpeg/ffprobe 工具指纹、RunManifest、内容寻址保全和现有 v0.1 CLI/ABI。

### 白绮仓库（项目能力）

- `Vivhite`/STS2 版本身份、Vulkan/窗口/OBS 预检和录制 producer；不进入 xAR 核心。
- STS2 `/state`、动作回执、OCR 执行、游戏恢复和语义 validator。
- S01–S10 分镜、卡牌机制、claims 文案、中文旁白、双语字幕内容、素材政策和
  Workshop/Mod 生命周期。
- `vivhite-promo-capture-v1` 项目 contract；通过 adapter 投影到 xAR 的通用 receipt。

### 明确不提取

STS2 transport 目前只有一个确定消费者，暂留 `sts2-ascend`/白绮侧；出现第二个
独立消费者后再评估独立插件。OBS、完整 NLE、OCR 引擎、平台账号和上传服务也不
进入 xAR 核心。

## 已落地的接口

- xAR 已发布并固定为 `v0.2.1`（tag commit
  `fb160b1eac10cbf1758ccf729f85b14c08e0c6e9`），加入 capture/evidence/audio/claims/review
  能力并保留 v0.1 兼容入口；该 patch 同时修正延迟 stem 先淡化源时间轴、再执行
  `adelay` 的确定性 filtergraph 顺序。发布物见
  [GitHub Release v0.2.1](https://github.com/XenoAmess/xar_promo_toolchain/releases/tag/v0.2.1)：
  wheel（190,405 bytes）SHA-256
  `f8de0711415e7fce2bf07a34d3db4edc0593f32ba1cb61034946665e27014621`，sdist（13,281,238 bytes）
  SHA-256 `56a712c03078a67a856f861d8c619dcdbd17967a4f26645c9c6e1643d14e4ad5`。
- 白绮侧提供 `VivhiteAdapter`、项目 capture contract、预检、TTS 产物和
  `render_capture_candidate.py`。候选 renderer 只消费同一 run 的哈希绑定录屏，
  在渲染前后复核 raw、contract、旁白和工具字节，并拒绝复用旧 run 目录。
- 游戏侧增加 opt-in `VIVHITE_PROMO_CAPTURE=1` 的 native debug surface 隐藏补丁；
  普通启动不受影响，录制后已恢复 RitsuLib 设置和隔离 marker。

## 验收状态

- 技术候选：delivery-a4 主片及 preview-a4 三版本均为 1920×1080/60 FPS、H.264
  `yuv420p`、AAC 48 kHz 双声道，并通过 ffprobe、全量音视频解码和 xAR 字节绑定审计；
  主片 SHA-256 为 `B50D787748D0D58570BC0C70D9C6D871BF92FDAC72D74ABDEDEE5A20C3D057D8`。
- 语义审核、人工 1.0× 审看、signoff/export 仍为 pending；候选不得宣传为最终成片。
- 首片不加外部 BGM；旁白 voice 固定为 `zh-CN-XiaoxiaoNeural`。

## 后续变更规则

新增能力只有在至少两个独立媒体项目复用、且 API 不含白绮/STS2 领域词时，才进入
xAR；否则先在白绮仓库实现。任何跨仓迁移必须保留旧 ABI，并在两侧更新本 ADR 或
对应迁移记录。
