# 启动 sts2-ascend 全套

## 结果

2026-08-30 通过 `sts2-ascend/scripts/Start-Agent.ps1` 启动整套自动游玩环境。最终状态为：本地 fork 构建成功，`STS2AIAgent` 的 DLL/PCK 已部署，游戏以 Vulkan 启动，runner、brain 和 ASCEND-VISION 均存活，Agent API 为 `http://127.0.0.1:8080`。

## 遇到的问题与处理

1. 第一次启动时，构建脚本解析到了 `C:\Program Files\dotnet\dotnet.exe`，该安装没有可见 SDK，导致构建失败。实际可用的 .NET 9 SDK 位于 `C:\Users\xenoa\AppData\Local\Microsoft\dotnet`；本次重试前将该目录置于 PATH 首位并设置 `DOTNET_ROOT`。
2. 第一次游戏启动早于 Steam 客户端，游戏日志出现 `k_ESteamAPIInitResult_NoSteamClient`，Agent API 一直不可用。启动 `D:\Steam\steam.exe` 后，用统一 Stop 入口清理半启动会话，再用统一 Start 入口重启，API 正常就绪。

## 后续注意

- 直接运行 Vulkan 启动脚本前应确保 Steam 客户端已经运行。
- 若构建再次提示没有安装 .NET SDK，应优先检查 `dotnet` 实际解析路径；本机 SDK 路径为 `C:\Users\xenoa\AppData\Local\Microsoft\dotnet`。
- 停止整套环境继续使用 `sts2-ascend/scripts/Stop-Agent.ps1`，不要按进程名泛杀组件。
