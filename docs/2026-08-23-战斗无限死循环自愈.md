# 2026-08-23 战斗无限死循环：根因、自愈机制与防患

## 根因分析（为什么落到这一步）

第 107 局在 F9 打 INKLET（墨宝）时卡了 **612 回合**的无限循环。实锤证据：

- **攻击牌全部在消耗堆**（exhaust）：上勾拳+、打击×4、幽灵之拳、痛击、防御×4 全在里面，
  抽牌堆/弃牌堆全空，手牌永远只剩 防御/坚毅。
- **元凶是【坚毅】(True Grit)**：每回合"获得格挡 + 消耗随机一张牌"。大脑每回合都打它，
  几百回合下来把攻击牌**全部耗尽**——敌人剩 1 血（还带着 149 层易伤）却再没有伤害牌能打，
  于是永远"格挡 → 结束回合"死循环。
- 叠加因素：我方 44 血 vs 敌方每回合 3 伤，格挡完全覆盖 → 死不了也赢不了。

**防患（已上线）**：消耗类牌（文本含"消耗"）**每场战斗最多打 4 次**，超出不再出。
这是通用防线（不绑定具体卡牌 ID），把"消耗光攻击牌"的可能性封死。

## 自愈机制（用户要求：大脑自己启动分析，无需人工）

1. **回合 ≥100** → 大脑自动（异步线程）启动 **AI 死循环分析**（opencode + k3）：
   把敌人/手牌/卡组/**牌堆（抽/弃/消耗）**发给模型，判定输出
   `VERDICT: grind`（正常磨血）/ `offense`（有牌没用对，应强攻）/ `giveup`（死循环，送死）。
2. **回合 ≥120 或 AI 判 offense** → 绕过评分阈值，有攻击牌就打最低血敌人。
3. **回合 ≥150 且 30 回合无掉血进展**（确定性兜底，不依赖 AI）→ **摆烂**：停止出牌、
   只结束回合，快速送死让本局终结（今晚实证：612 回合时触发，INKLET 几轮打死我们，正常结算）。
4. AI 判 grind → 宽限期，继续打。

真机验证：新大脑上线 → 识别回合超限 → 启动 AI 分析（判 offense，因提示词没带消耗堆信息误判）
→ 强攻无牌可打 → 38 回合无进展 → 兜底摆烂 → 终结本局 → 开新局。**全链无人工**。
（AI 提示词随后已补消耗堆信息，下次此类场景会直接判 giveup。）

## 教训

- "消耗其他牌"的卡在长战斗中是把双刃剑，必须限制使用频率。
- 兜底逻辑要**不依赖 AI 可用性**：AI 判错/缺席时，确定性的"无进展送死"也能收尸。
- 牌堆字段在 `state.agent_view.combat.{draw,discard,exhaust}`（顶层 combat 载荷没有）。
