2026-09-26 调查期间，正在运行的 `XR4TW5XYU99A` 在第 14 层再次出现同类循环。随即通过统一入口下播并 `Stop-Agent.ps1 -KeepGame`，保留原生游戏现场，不注入动作、不手改学习数据。

## 奖励 UI 生命周期

旧逻辑把根奖励列表、卡牌候选与 `pending_card_choice` 一起作为奖励实例身份。打开卡牌子页后，原生 API 暂时返回 `rewards=[]`；跳过后根列表再次出现。每次变化都清空已经取得成功回执的奖励防重状态，导致相同卡牌奖励被立即再次打开。仅删除身份中的 `card_options` / `pending_card_choice` 仍不够，因为子页隐藏了根列表。

修复以可见根列表识别奖励实例，并在卡牌子页期间保留它。卡牌失败冷却单独跟随当前候选。真实根列表变化、重排、新 run/楼层以及实际离开奖励房间仍可释放旧身份；短暂 `UNKNOWN` / `WAITING` 不充当新奖励。无成功回执的操作仍可正常重试。卡牌评分和取舍阈值不属于本次 UI 协调修复。
