# 2026-08-22 创建 AGENTS.md 工作流程规范

## 背景

项目为 Slay the Spire Mod，初期结构较空（仅 `src/`、`.idea/`、`.gitignore`）。
为规范 AI 助手的工作流程，创建了 `AGENTS.md`。

## 本次改动

- 新增 `AGENTS.md`，定义两条核心工作流规则：
  1. 完成任何任务后默认执行 `git commit` + `git push`，无需再次确认。
  2. 完成任何任务后将经验总结写入 `docs/` 目录，文件命名建议 `YYYY-MM-DD-主题.md`。

## 经验总结

- `AGENTS.md` 放在项目根目录，编码助手会自动读取并遵循其中的约定。
- 规则描述要**明确且可执行**（例如"默认执行，无需确认"），避免模糊措辞导致助手反复询问。
- 经验总结文档采用日期 + 主题的命名方式，便于按时间线检索。

## 注意事项

- 当前仓库**未配置 git 远程仓库**（`git remote -v` 为空），`git push` 会失败。
  需要先用 `git remote add origin <url>` 配置远程仓库后才能推送。
