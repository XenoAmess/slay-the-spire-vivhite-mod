# 白绮回复数值调整

## 本次结论

- `孤高冠冕` 的击杀回复最终调整为 `ceil(最大生命 × 20%)`，仍按每个敌人死亡事件即时结算且不设置自定义上限。
- 汲取继续按整张攻击造成的实际敌方生命损失汇总，多段与群体攻击只结算一次；最终结果由向下取整改为向上取整。
- 所有由白绮卡牌提供的汲取百分比、临时/永久汲取百分点以及后续触发增长，在整数化后连续执行两次翻倍；最终值为原设计值的 `4×ceil(旧值/5)`。非汲取回血没有变化。

## 实现注意事项

- 汲取取整必须位于攻击聚合结束之后，不能逐段向上取整，否则多段牌会被重复放大。
- 既有结算顺序保持为“仪式謦欬 → 固定謦欬 → 攻击 → 汲取 → 孤高冠冕”；验收测试固定所有带固定謦欬的攻击必须经过 sealed 的“支付成功后才执行牌面效果”基类，因此该牌引发的汲取与击杀回血不能早于謦欬。
- `无限画布` 与 `统一场论` 的成长由 Power 在后续事件中产生，不能只修改卡牌 DynamicVar；运行时 Power 系数也必须同步。
- 双语卡牌描述大多通过 DynamicVar 展示，不应把动态数值再次硬编码到文本。遗物描述同样通过 `{Heal}` 展示 20%。
- 运行时不重新应用历史换算；源码、Brain 与测试均直接登记上表最终整数。
- 引擎仍以整数生命结算；本次没有增加单牌、单回合、单场或百分比上限。
