# 2026-08-26 PR #48 评论修复与全链路审查

## 结论

上游 PR #48 的唯一一条需要代码处理的维护者评论是准确的：首版虽然把
`crystal_sphere` 放进了完整 `/state`，但默认 MCP `get_game_state` 读取的是
紧凑 `agent_view`，因此智能体会看到 `crystal_clear_cell` 动作，却拿不到棋盘坐标。
这就是“直接 HTTP 真机测试能通过，正常 Agent 仍可能卡住”的根因。

逐项检查了普通评论、review、inline thread、commit comment 与检查注解；其余内容是
自动审查状态/额度提示，没有遗漏待处理的代码意见。

## 评论修复

- `BuildAgentViewPayload` 现在返回 `crystal_sphere`，完整状态与紧凑状态的棋盘契约一致。
- 增加默认 guided `get_game_state` 回归，明确验证返回的紧凑状态包含棋盘与动作。
- 状态结构发生变化后同步升级 `StateVersion 10 -> 11`、`AgentViewVersion 5 -> 6`。

## 全量自审额外发现

1. **动作参数只打通了 raw HTTP**：`x/y/tool` 原先停在 C# `ActionRequest`，Python
   guided/full MCP、`Sts2Client`、游戏内 Agent schema/loop/bridge 与无 tools JSON
   fallback 都不能传。现已全链路贯通并加回归。
2. **工具模型状态与 UI 高亮可能不一致**：游戏自己的 `SetBigDivination` /
   `SetSmallDivination` 会同时更新 minigame 与两个按钮；直接 `SetTool` 只改模型。
   现在额外同步 `%BigDivinationButton` / `%SmallDivinationButton` 的 active 状态。
3. **反射失败没有诊断**：私有 `_entity` 查找、类型不符、读取异常，以及按钮节点缺失/
   同步异常现在都有 warn-once 日志，既可排查未来游戏版本变化，也不会每帧刷屏。
4. **settle 判定会假阳性**：同屏暂时拿不到 `_entity` 不代表点击完成。现在要求实际观察到
   `DivinationCount` 下降、奖励子屏接管，或最终 `proceed` 可用；后者优先于 entity 可用性，
   避免最后一次占卜无意义等待 10 秒。
5. **显式 JSON null 被误读**：通用 `ReadString` 会把 `tool: null` 变成字符串 `"null"`，
   导致可选工具参数收到 400。现在 Null/Undefined 保持 C# null，并覆盖无 tools 模式。
6. **Python schema 太宽**：MCP 的工具参数原来只是任意 string；现用 Literal 将 schema
   收窄为 `big | small`，让模型在调用前即可看到合法值。
7. **PR 分支夹带无关提交**：旧 head 还包含后续的解锁私有基类字段修复。已从最新
   upstream/main 重建干净分支，只保留水晶球功能与本轮审查修复；解锁修复继续独立维护。
8. **文档与使用入口不完整**：补齐 API、MCP README、内置 PlayPrompt 和 skill screen
   playbook，明确棋盘字段、动作参数、诅咒规避与奖励子屏流程。

## 方法论与踩坑

- **必须按默认用户路径验收**：raw `/state` + raw `/action` 成功，只能证明底层 API；还要
  分别验证 compact `agent_view`、guided/full MCP、游戏内 Agent tools 与无 tools fallback。
- **状态和动作必须成对贯通**：动作存在但缺状态，与状态存在但参数传不到，最终表现都一样——
  智能体卡屏。新增屏幕时应做“状态可见性 × 参数传递 × settle”三项契约检查。
- **反射兼容代码必须可观测**：找不到私有成员时宁可返回不可操作并打一条限频告警，不能静默
  暴露动作或假报 stable。
- **不要整文件清理混合换行**：旧提交把 CRLF 字符带进了新增 hunk；直接统一整文件会把 PR
  膨胀成上万行 EOL diff。正确做法是保留基线行的原始字节，只规范相对 upstream 新增/修改的
  hunk，并用 `git diff --check` 和最终 stat 双重确认。
