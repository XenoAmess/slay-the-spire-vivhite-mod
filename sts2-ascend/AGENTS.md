# sts2-ascend 工作规则

本目录及全部子目录继承仓库根 `AGENTS.md`。以下规则在自动游玩、复盘、生命周期和知识库任务中再次强调，优先级最高：

- 如果不能用用户明确需求、当前真实故障、可复现测试、运行日志或现有数据证明必要性，严禁消耗用户的模型额度和时间研究、设计或实现额外安全边界。
- 任何新门禁、限制、威胁模型或防御机制都必须先写明必要性证据和预期收益；证明不了就停止，不得用“理论上可能”扩张任务。
- 不得自行把 symlink、gitlink、prompt 篡改、路径逃逸等假设场景列为待办。只有已经发生、能够复现、用户明确要求，或存在迫近且不可逆的数据损失/凭据泄露风险时才处理。
- 目标是相对安全、可观测、可记录、可回退和运营有效。优先最小有效修复、分批提交；严禁以安全为由收紧 GLM 可提交文件范围或恢复全仓指纹/脏状态门禁。
