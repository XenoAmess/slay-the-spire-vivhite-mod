3. **卡组构建问题：两局共拿 2 牌，输出/防御双缺**

### 三、新沉淀的经验知识

1. **"掉血1（阵亡）"要回溯归因**：致死战的掉血量接近 0 时，真正死因是此前 2~3 个节点的累计失血，复盘必须看完整 combat_notes 链而非只看死因敌人。

### 三、新沉淀的经验知识

1. **仿真器正确 ≠ 决策正确**：路径模拟把"预计进 Boss 血量 65%"预测得分毫不差，但目标函数允许用光药水和锻造机会去换血量百分比。评价决策系统要看它优化的目标，不只看执行精度——"精确地走向错误目标"比"粗糙地走向正确目标"更危险。
2. **减权要乘在承诺上，不是乘在首项上**：一个选项的总分包含其后续子树的组合收益（精英+篝火回血），只罚触发项的首节点权重，子树优势会把惩罚完全吞掉。凡是"选择 X 就承担 X 全部后果"的决策，惩罚必须作用在该选项的最终总分上。
3. **资源的价值有场景梯度**：增益药水在顺风波里使用是负价值（机会成本=Boss 战空手）。`hard`（需要资源）与 `premium`（值得动用储备资源）必须是两个阈值。
4. **生存判定要有"余量"维度**：致死（gap≥hp）与安全之间隔着"惨胜区"——本回合活下来但下回合必死的局面应按致死处理。皮血线 = max_hp 的 12% 是当前标定值。
5. **统计因子要防幸存者偏差**：用 outcome 给"房间类型"加权时，高危房的到访记录天然来自强局，因子系统性偏高。对风险类节点该因子只能做减法不能做加法。

### 三、新沉淀的经验知识

1. **死亡率不是危险的唯一签名**：一个组合可以很少直接杀人、却每场稳定咬掉你三分之一血条——这种「钝刀」在低血量时同样是处决者。危险评估要同时看频率维度（死亡率）和强度维度（场均战损占血条比），两者任一超标都应收紧姿态。
2. **资源规则隐含的假设要显式化并校验**：「Boss 前夜回血优于锻造」隐含假设"回血量能覆盖预期战损"。63 局满血入场照样被处决，证明该假设在高战损 Boss 面前崩塌——此时回血是无效投资，唯一边际收益在缩短战斗。规则失效的场景要用数据（Boss 分档统计）显式识别，而不是靠参数微调。
3. **结算口径决定学习方向**：事件选项的价值若只记即时 hp/gold，「免费拿一张牌」永远记 0 分——而一张不可打出的牌在整个后半程持续占据手牌位。隐性成本（卡组稀释、手牌污染）必须进结算口径，否则探索会在同一个看似免费的坑里反复跌倒。

### 三、新沉淀的经验知识

1. **"成功"也要进协议校验**：动作返回状态是引擎与服务端的隐式契约，白名单漏一个词就让每一次成功都被记为失败。凡"按状态分类"的逻辑，都必须用真实响应样本做兜底校验，不能凭想象枚举。
2. **位置索引是跨 tick 状态的地雷**：把 UI 序号存进记忆之前必须回答"下一帧这个序号还指向同一个东西吗"。黑名单类机制的失效条件必须与其引用对象的变化事件绑定（此处 = 手牌数量变化即 index 语义重置），否则防护本身会变成攻击。
3. **弃权回合是最贵的决策错误**：一次错误的 end_turn = 白吃一整轮意图 + 整轮能量作废，期望代价远高于打出一张评分平庸的牌。日志审计应优先扫「可出牌在手却结束回合」模式——它是静默失效逻辑的第一指纹。
4. **危险画像是双指标的**：62~64 从战损强度维度认出"钝刀型"组合（FLYCONID 类），65~66 从死亡频率维度认出"处决型"组合（FUZZY+SHRINKER 类，场均战损恰好低于战损阈值）——单一维度各漏一半杀手。死亡率与场均战损占血条比，任一超标都要收紧。
5. **软上限必须有执行牙齿**：没有准入门槛配合的上限只是减分项，注定被高基础分选项碾压。"上限"的正确实现是"门槛抬升"，而非"价格折扣"。
6. 观察点（下批复盘）：缺陷①修复前后对比要先把「大脑重启时间线」核清楚——65~66 两局与更早批次一样，可能跑在部分修复生效前的旧进程里；行为标记（用药/出牌数）才是生效与否的裁判，代码库状态不是。
