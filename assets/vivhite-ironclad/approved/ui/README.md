# Approved UI 素材

这里是当前通过静态素材门禁的五张 UI PNG。它们是独立图像，不是 atlas 页：

- `icon.png`、`icon_outline.png`：角色图标及其描边；
- `map_marker.png`：地图标记；
- `select.png`、`select_locked.png`：选人界面状态图。

发布前仍须由 `Vivhite` 的实际 UI 消费者确认尺寸、锚点和缩放；本目录不包含 `.import` 缓存，也不承担自动复制到运行时的职责。生成血缘和完整 Prompt/请求参数见 [`../../generated/evolink-paid/README.md`](../../generated/evolink-paid/README.md)，集合状态见 [`../README.md`](../README.md)。
