# Character-select 制作源

本目录只保存选人界面使用的白绮源图：

- [`sources/vivhite-character-select-hero-master-v1.png`](sources/vivhite-character-select-hero-master-v1.png)：英雄母源；
- [`sources/vivhite-character-select-magic-sigil-v1.png`](sources/vivhite-character-select-magic-sigil-v1.png)：独立魔法印记。

它们要配合 `Vivhite/Vivhite/skins/ironclad/spine/character_select/` 的私有 skeleton、atlas 和转场材质使用。这里没有 atlas 或运行时 `.import` 产物；复制到运行时前必须通过选人场景的尺寸、Alpha、层序和转场契约。
