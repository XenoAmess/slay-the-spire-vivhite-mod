# UI 制作源

本目录包含多人手势的四张 PNG：`point.png`、`rock.png`、`paper.png`、`scissors.png`。它们是用户于 2026-08-28 明确批准的**唯一历史污染素材封闭例外**，从隔离区逐字节恢复；不得把这些文件作为 AI 参考、不得重做 Alpha，也不得把例外扩展到其他 UI 或衍生链。

正式 UI 图标（`icon`、`icon_outline`、`map_marker`、`select`、`select_locked`）位于 [`../../approved/ui/`](../../approved/ui/README.md)。两组素材都必须经过实际 UI 消费者的尺寸/锚点检查，不能因文件名相似而互换。
