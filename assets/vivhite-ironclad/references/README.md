# 干净参考图

本目录保存用户提供、可作为新生成起点的两张原始参考：

- [`character-design.png`](character-design.png)：角色全身/服装设定参考；
- [`face-reference.jpg`](face-reference.jpg)：脸部、银发、紫瞳与金色眼镜参考。

它们是只读事实源，不是运行时贴图、atlas 或已验收候选。任何新透明素材必须从这里或已验真的干净设定图开始，经 EvoLink `gpt-image-2` 原生透明路径生成，并在 `generated/` 追加归档完整 Prompt、请求参数和原图。不得用 `legacy-contaminated/`、程序抠图或带污染血缘的文件替代本目录参考。
