# Codex-native 生成记录

这里保存 2026-08-31 起按批次归档的本地生成实验，主要包括白绮卡图、能力图和选人转场候选。叶目录以 `original.png`、`prompt.txt`、`generation*.json` 为最小事实三件套；验收证据通常放在 `inspection/`，`scale-transformation-attempt-03` 等历史批次则以同目录的 `evidence-audit.md` 记录。被拒绝的完整批次转入 [`../discarded/`](../discarded/README.md)。

这些记录用于追溯和离线比较，不能仅凭“生成成功”晋级运行时。需要透明背景的新素材仍必须遵守仓库唯一 EvoLink 原生透明硬契约；任何本地生成结果都必须按实际用途重新确认 RGBA、SourceOver、尺寸和源码消费者，并在报告中明确允许的边界。
