# 白绮 AI 美术废弃稿归档

本目录是受 Git 跟踪的追加式废弃稿归档。凡已有明确验收记录判定为
`rejected`、`discarded`、`not_for_runtime` 或同等状态的 AI 生成批次，均按完整批次复制到这里。

归档规则：

- 保留模型返回的原图、逐字 Prompt、脱敏后的实际请求参数、生成事实与验收结论；
- 保留原生成目录，不移动、不覆盖、不删除原始记录；
- 本目录中的文件不得接入运行时，也不得作为后续 AI 生成参考；
- 只归档已有明确废弃证据的批次；状态不确定的候选继续留在原目录，等待人工裁决；
- 每个批次保持原 provider、日期和批次目录结构，便于和原始记录逐字节核对；
- 相同文件在 Git 对象库中按内容寻址去重，工作树副本只用于提供清晰的废弃稿入口。

该归档不表示素材没有保存价值。相反，废弃稿同样消耗了生成额度，也记录了失败原因和设计边界，
因此必须像采用稿一样可追溯、可复核、可恢复。
